# 热学包内容规范（M7）

> 适用：`src/demos/thermo/*`  
> 目标：命名、单位、教学字段与验收清单统一；目录分类顺序见 `catalogPlan.CATEGORY_ORDER`。

## 1. 命名

| 项 | 约定 | 示例 |
|----|------|------|
| Demo `id` | `thermo-<topic>`，小写 + 连字符 | `thermo-maxwell` |
| 模型工厂 | `createXxxModel` | `createMaxwellModel` |
| Adapter | `createXxxAdapter` | `createMaxwellAdapter` |
| Meta 导出 | `xxxMeta` | `maxwellMeta` |
| 注册函数 | `registerXxxDemo` | `registerMaxwellDemo` |
| 单测 | 同目录 `*.spec.ts` | `maxwell.spec.ts` |
| 封面 | `public/covers/<id>.png` + `LIVE_COVERS` | `thermo-gas.png` |

- `subject` 固定为 `热学`。
- `category` 用教材分类（见下表顺序）。
- `tags` 3～6 个短词。

## 2. 分类顺序（目录）

| 顺序 | category | 已落地 / 规划 |
|:----:|----------|---------------|
| 1 | 分子动理论 | `thermo-gas`、`thermo-maxwell`、`thermo-mfp`、`thermo-diffusion`；规划：碰撞截面加深 |
| 2 | 理想气体定律 | `thermo-ideal-gas` |
| 3 | 热力学过程 | `thermo-pv-process` |
| 4 | 热力学循环 | `thermo-carnot` |
| 5 | 熵与不可逆 | `thermo-entropy` |

## 3. 参数与单位

| 规则 | 说明 |
|------|------|
| 教学简化 | 可取 \(k_B=1\)、\(m=1\)、\(nR=1\)，须在 `docs.insight` 标明 |
| 温度 | 参数 `T` 为相对温度尺度（非强制开尔文 UI） |
| 粒子数 | 硬上限（如 `MAX_N≤80`），避免主线程卡顿；大 N 走 Worker |
| `ParamDef` | 数值须有 `min`/`max`/`step`/`unit`；过程类型用 `select` |
| 衍生量 | \(v_p,v_{avg},v_{rms}\)、功 \(W\)、\(\lambda\) 等由 `observe().values` 输出 |

## 4. 可视化约定

- 分子盒子：2D 俯视；碰撞闪光勿遮挡顶栏 HUD。
- 分布/直方图：解析曲线与采样柱叠画，标出 \(v_p / v_{avg} / v_{rms}\)。
- P–V 图：轴标签清晰；当前状态点 + 过程轨迹；功用半透明面积。
- 3D 仅示意，不以写实为目标。

## 5. DemoDocs 最低集

与力学包相同：`title` / `summary` / `concept`≥2 / `objectives`≥2 / `formulas`≥2 / `steps`≥2（含 bindings）/ `challenges`≥1 / `readouts`≥4 / `legend`+`insight`；视图至少 `canvas2d`+`docs`，推荐 `chart`/`three`。
