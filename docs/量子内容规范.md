# 量子 / 近代物理内容规范（M7）

> 适用：`src/demos/qm/*`  
> 目标：命名、教学简化常数、助学字段与目录分类统一。

## 1. 命名

| 项 | 约定 | 示例 |
|----|------|------|
| Demo `id` | `qm-<topic>` | `qm-barrier` |
| 模型 / Adapter / Meta / register | 与力学包相同驼峰约定 | `createBarrierModel` |
| 单测 / 封面 | `*.spec.ts` / `public/covers/<id>.png` | — |

- `subject` 固定为 `量子力学`（近代实验类演示亦挂此学科，便于目录聚合）。
- `category` 见下表。

## 2. 分类顺序

| 顺序 | category | 已落地 / 规划 |
|:----:|----------|---------------|
| 1 | 束缚态 | `qm-well`、`qm-oscillator` |
| 2 | 散射与隧道 | `qm-barrier` |
| 3 | 近代实验 | `qm-photoelectric`、`qm-compton`、`qm-blackbody`、`qm-double-slit`、`qm-alpha` |

## 3. 参数与单位

| 规则 | 说明 |
|------|------|
| 教学常数 | 常用 ħ=1、m=1、c=1；光电可用 eV / 频率相对单位，须在 insight 标明 |
| 波函数 | `observe` 输出采样数组 `psi`/`dens`/`re`/`im` 等 Float32Array |
| 透射系数 | 解析或半解析优先；重数值轨道（α 散射）走 Worker |
| 禁止 | 在 pedagogy 写死 demo 公式数值；衍生量一律 `observe` |

## 4. 可视化约定

- 势阱/势垒：壁与经典禁区用半透明填充；能量水平线醒目。
- 概率密度与 Reψ 用不同颜色；避免与顶栏 HUD 重叠。
- 3D：复曲线 `(x,Re,Im)` 或势能曲面示意即可。
- 光电/康普顿/黑体：装置示意 + 关键曲线，不追求实验室写实。

## 5. DemoDocs 最低集

与力学包相同（concept / objectives / formulas / steps+bindings / challenges / readouts / legend+insight）。
