# 光学包内容规范（M5-12）

> 适用：`src/demos/optics/*`  
> 目标：命名、单位、光路/偏振可视化约定与验收清单统一；目录分类顺序见 `catalogPlan.CATEGORY_ORDER`。

## 1. 命名

| 项 | 约定 | 示例 |
|----|------|------|
| Demo `id` | `opt-<topic>` | `opt-double-slit` |
| 模型工厂 | `createXxxModel` | `createDoubleSlitModel` |
| Adapter | `createXxxAdapter` | `createDoubleSlitAdapter` |
| Meta / 注册 | `xxxMeta` / `registerXxxDemo` | `malusMeta` |
| 单测 / 封面 | `*.spec.ts` / `public/covers/<id>.png` | `opt-malus.png` |

- `subject` 固定为 `光学`。
- `category` 用教材分类（见下表顺序）。

## 2. 分类顺序（目录）

| 顺序 | category | 已落地 / 规划 |
|:----:|----------|---------------|
| 1 | 几何光学 | `opt-refraction`；规划：薄透镜 |
| 2 | 干涉 | `opt-double-slit`；规划：薄膜干涉 |
| 3 | 衍射 | `opt-diffraction`；规划：光栅 |
| 4 | 偏振 | `opt-malus`、`opt-waveplate`；规划：双折射 |

## 3. 参数与单位

| 规则 | 说明 |
|------|------|
| 波长 / 缝宽 | 教学单位可取 μm 量级；画面与公式同一套符号 |
| 角度 UI | 度；Jones / 斯涅尔内部用弧度 |
| 强度 | 归一或相对 I₀；屏上光斑/条纹亮度∝I |
| 偏振 | 透振/快轴用刻线或双箭头；状态条勿用 `sy(yMax)-N`（会裁切） |

## 4. 可视化约定

- **形成过程优先**：干涉/衍射画空间 \|ψ\|² 或惠更斯；偏振画矢端轨迹；折射扫描入射角。
- 状态条用**屏幕坐标**贴顶（`boxY≈10`），避免与坐标轴重叠。
- 2D 各向同性；光路箭头用 `drawArrow`，偏振片/波片用圆盘+刻线。
- 3D 为辅助示意（偏振片、波片、界面）。

## 5. DemoDocs 最低集

同力学 / 电磁包：助学字段齐全；挑战覆盖关键极限（如消光、圆偏振、全反射）。
