# 力学包内容规范（M4-01）

> 适用：`src/demos/mechanics/*`  
> 目标：命名、单位、教学字段与验收清单统一，便于新增演示时对照。

## 1. 命名

| 项 | 约定 | 示例 |
|----|------|------|
| Demo `id` | `mech-<topic>`，小写 + 连字符 | `mech-energy-curve` |
| 模型工厂 | `createXxxModel` | `createEnergyCurveModel` |
| Adapter | `createXxxAdapter` / `XxxAdapter` | `createEnergyCurveAdapter` |
| Meta 导出 | `xxxMeta` | `energyCurveMeta` |
| 注册函数 | `registerXxxDemo` | `registerEnergyCurveDemo` |
| 单测文件 | 与主文件同名 `*.spec.ts` | `energyCurve.spec.ts` |
| 封面资源 | `public/covers/<id>.png` | `mech-pendulum.png` |
| 目录登记 | `LIVE_COVERS[id]`；规划条放 `PLANNED_SOON` | — |

- `subject` 固定为 `力学`（一期力学包）。
- `category` 用中文教材分类名（如 `质点运动学`、`振动`、`波动`、`刚体力学`、`动能和势能`、`动量和角动量`）。
- `tags` 3～6 个短词，便于目录过滤。

## 2. 参数与单位

| 规则 | 说明 |
|------|------|
| SI 为主 | 长度 m、时间 s、质量 kg、力 N、能量 J、角速度 rad/s |
| 角度 UI | 滑块可用「度」；模型内部统一弧度，observe 可再输出 `°` |
| `ParamDef` | 必填 `key` / `label` / `kind` / `default`；数值须有 `min`/`max`/`step`/`unit` |
| 禁止混用 | 同一 key 不要既当「度」又当「弧度」输出；用 `theta`+读数单位区分 |
| 衍生量 | 由 `observe().values` 给出（如 `tMax`、`period`、残差 `residual`），勿在 pedagogy 里写死公式 |

## 3. 时间与播放

- 必须输出 `tMax`（或 `meta.time.maxKey` 指向的键）。
- 过程结束时 `done === 1`；支持 `seek(t)` 以便 scrub。
- 壳层「循环」勾选后由播放器复位，demo 无需自写循环逻辑。

## 4. DemoDocs / 助学最低集

每个可玩演示至少包含：

- [ ] `docs.title` / `summary`
- [ ] `concept` ≥ 2 条
- [ ] `objectives` ≥ 2 条
- [ ] `formulas` ≥ 2 条（KaTeX）
- [ ] `steps` ≥ 2 步，含 `bindings`
- [ ] `challenges` ≥ 1 个（`paramNear` / `valueNear` / `all`）
- [ ] `readouts` ≥ 4 个常用量
- [ ] `legend` + `insight`
- [ ] `views`：至少 `canvas2d` + `docs`；推荐 `chart` / `three`

## 5. 文件与注册清单

新增力学演示时勾选：

- [ ] `xxx.ts`（model + meta + register）
- [ ] `xxxAdapter.ts` + `renderXxx2d.ts`（3D 可选）
- [ ] `xxx.spec.ts`（极限 / 守恒 / `tMax` 至少一类）
- [ ] `demos/index.ts` 调用 `registerXxxDemo()`
- [ ] `LIVE_COVERS` 登记；有截图则放 `public/covers/<id>.png`
- [ ] **不修改** `DemoPlayer.vue`

## 6. 验收对照（单演示）

| 级别 | 要求 |
|------|------|
| P0 | 可从目录打开；调参即时；播放/复位/scrub 正常 |
| P1 | 公式与画面量一致；挑战可完成 |
| P2 | 单测覆盖关键极限或守恒；封面非占位 |

全包抽检见 [力学包抽检报告.md](./力学包抽检报告.md)（M4-16）。
