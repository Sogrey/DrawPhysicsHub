产品原则
  • 参考既有教学演示的教学意图与科目分类，不 1:1 克隆第三方动态几何构造树 / CAS
  • 架构：物理模型层（可单测）+ 渲染层（Canvas2D / Three.js / Chart）+ Vue 应用壳
  • 产能靠场景模板复用；内容按科目包迭代，不做 1900 全量搬迁
  • 超越点：性能、移动端、对比双视图、课程路径、自动化抽检、无外挂运行时
  • 文档双端：同名 .md 供 AI；本 HTML 供人工勾选，进度须同步
