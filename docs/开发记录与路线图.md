## 2. 开发记录（按里程碑）

### 2.1 一期骨架（M1–M3）

| 时间窗 | 内容 |
|--------|------|
| M1 | Vue3 + Vite + pnpm；`DemoMeta` / model / registry；RK4、受限表达式、场采样；Canvas2D + Three + Chart |
| M2 | 三栏教学壳、目录学科树、封面、`tMax`、助学协议、全屏 / FPS / i18n |
| M3 | 未单独立项；能力沉淀为 `DemoAdapter` + `primitives2d/3d` + composables |

### 2.2 力学样板包（M4）

- 15 个可玩演示（抛体样板 → 振动 / 刚体 / 波动 / 能量 / 角动量等）
- [力学内容规范](./力学内容规范.md) + [力学包抽检报告](./力学包抽检报告.md)（56 项单测）
- Adapter 验收：新增演示不改 `DemoPlayer.vue`

### 2.3 电磁 / 光学（M5）

- 电磁 9：点电荷、电势、偶极、直导线 B、圆环 B、回旋、安培力、楞次、动生
- 光学 9：双缝、单缝、马吕斯、波片、折射、透镜、薄膜、光栅、双折射
- 场密度自适应、干涉公式↔画面、偏振 3D 相机预设
- [电磁光学抽检报告](./电磁光学抽检报告.md)

### 2.4 跨学科代表条（M5 尾声 / M7·M8 先行）

| id | 要点 |
|----|------|
| `thermo-gas` | 分子碰撞与压强示意 |
| `thermo-carnot` | 卡诺循环 P–V |
| `qm-well` | 无限深势阱；2D ψ/\|ψ\|²/Re + 位相钟；3D 复曲线 `(x,Re,Im)` |
| `theo-coriolis` | 科里奥利；2D `a_cor⊥v`；3D 水平转盘 `(x,y)→(x,z)`，`Ω∥Y` |

关键点修复（已记入 [一期已知问题](./一期已知问题.md)）：
