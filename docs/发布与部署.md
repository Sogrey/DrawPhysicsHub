# 发布与部署（M6-01）

> 线上目标：GitHub Pages · `https://sogrey.github.io/DrawPhysicsHub/`  
> Vite `base`：`/DrawPhysicsHub/`（见 `vite.config.ts`；路由用 `import.meta.env.BASE_URL`）

## 本地生产构建

```powershell
pnpm install
pnpm test          # 建议发版前跑全量
pnpm build         # vue-tsc + vite build + spa-404
pnpm preview       # 本地预览 dist（注意仍带 /DrawPhysicsHub/ 前缀）
```

`pnpm build` 末尾会执行 `scripts/spa-404.mjs`，把 `dist/index.html` 复制为 `dist/404.html`，避免 GitHub Pages 上 history 路由深链刷新 404。

**验收（2026-11-23 本地）：**

| 项 | 结果 |
|----|------|
| `pnpm build` | ✅ 退出码 0 |
| `dist/index.html` 资源路径 | ✅ `/DrawPhysicsHub/assets/...` |
| 产物体量 | ~8.4 MB（含 KaTeX 字体与封面 png） |
| 主 JS chunk | ~1.3 MB（gzip ~373 KB）；见 [一期已知问题](./一期已知问题.md) |

## CI / GitHub Pages

工作流：[`.github/workflows/deploy.yml`](../.github/workflows/deploy.yml)

- 触发：`push` 到 `main`，或手动 `workflow_dispatch`
- 步骤：`pnpm install --frozen-lockfile` → `pnpm test` → `pnpm build` → SPA 404 → `upload-pages-artifact` → `deploy-pages`
- 仓库需：Settings → Pages → Source = **GitHub Actions**

首次或改 workflow 后，在 Actions 里确认 Deploy 成功，浏览器打开：

`https://sogrey.github.io/DrawPhysicsHub/`

抽检：目录页能进、任选力学/电磁/光学/量子各 1 条可播放。

## 封面与清单

| 命令 | 用途 |
|------|------|
| `pnpm list:demos` | 生成 / 核对 [`演示清单.md`](./演示清单.md) |
| `node scripts/capture-covers.mjs` | 更新 `public/covers/*.png`（需先 `pnpm dev`；清单见 `cover-demos.mjs`） |
| `DPH_COVER_BATCH=m7` | 只重抓 M7 新演示封面 |
