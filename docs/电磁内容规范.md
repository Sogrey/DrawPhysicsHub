# 电磁包内容规范（M5-11）

> 适用：`src/demos/em/*`  
> 目标：命名、单位、场可视化约定与验收清单统一；目录分类顺序见 `catalogPlan.CATEGORY_ORDER`。

## 1. 命名

| 项 | 约定 | 示例 |
|----|------|------|
| Demo `id` | `em-<topic>`，小写 + 连字符 | `em-point-charge` |
| 模型工厂 | `createXxxModel` | `createPointChargeModel` |
| Adapter | `createXxxAdapter` | `createPointChargeAdapter` |
| Meta 导出 | `xxxMeta` | `pointChargeMeta` |
| 注册函数 | `registerXxxDemo` | `registerPointChargeDemo` |
| 单测 | 同目录 `*.spec.ts` | `pointCharge.spec.ts` |
| 封面 | `public/covers/<id>.png` + `LIVE_COVERS` | `em-wire-b.png` |

- `subject` 固定为 `电磁学`。
- `category` 用教材分类（见下表顺序）。
- `tags` 3～6 个短词。

## 2. 分类顺序（目录）

| 顺序 | category | 已落地 / 规划 |
|:----:|----------|---------------|
| 1 | 静电场 | `em-point-charge`、`em-dipole`；规划：电势线、高斯面 |
| 2 | 电流磁场 | `em-wire-b`；规划：载流圆环 B |
| 3 | 洛伦兹力 | `em-cyclotron`；规划：安培力 |
| 4 | 电磁感应 | `em-lenz`；规划：动生电动势 |

## 3. 参数与单位

| 规则 | 说明 |
|------|------|
| SI 教学单位 | 可取 k=1、μ₀/4π=1 等简化常数，须在 `docs.insight` 或公式旁标明 |
| 角度 UI | 度；内部计算用弧度 |
| 场量 | `observe` 输出 E/B 分量或模；箭头绘制走共享场可视化原语 |
| 电荷符号 | `q>0` 红 / `q<0` 蓝（与现有场演示一致） |

## 4. 场可视化约定

- 2D 场线 / 箭头：**各向同性**世界坐标（`isotropic: true`），避免椭圆畸变。
- 直导线 B：2D 同心圆；3D 用圆环磁力线，勿缺画。
- 箭头密度：用 `adaptiveFieldDensity`（视口像素 → linesPerCharge / arrowEvery）；禁止写死过密网格导致掉帧。
- 3D 仅示意，不以写实渲染为目标。

## 5. DemoDocs 最低集

与力学包相同：`title` / `summary` / `concept`≥2 / `objectives`≥2 / `formulas`≥2 / `steps`≥2（含 bindings）/ `challenges`≥1 / `readouts`≥4 / `legend`+`insight`；视图至少 `canvas2d`+`docs`，推荐 `chart`/`three`。
