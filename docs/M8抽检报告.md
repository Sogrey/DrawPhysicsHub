## 3. 抽检原则

1. **极限 / 对称**：如 γ(β=0)=1、阿特伍德等质量 a=0、拉比 π 脉冲 Pe=1、衰变 T½ 减半。
2. **公式一致**：observe 读数与导出纯函数一致（`lorentzGamma`、`ottoEfficiency`、`velocityAdd` 等）。
3. **协议**：`time.maxKey` / `seek` / `tMax` 可用。
4. **工程**：封面 PNG 存在；课次包只引用 live id；目录可切换课次浏览。
5. **不替代教研**：定性以教材为准。
