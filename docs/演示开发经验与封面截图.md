## 1. 新增一个演示的标准路径

按这个顺序做，少返工：

1. **定 id / 分类**  
   - 力学 `mech-*`、电磁 `em-*`、光学 `opt-*`  
   - `subject` + `category` 必须落在 `catalogPlan.CATEGORY_ORDER` 的教材序里（否则会排到分类末尾）

2. **模型 `createXxxModel()`**  
   - `init` / `step` / `seek` / `observe` / `reset` / `setParams`  
   - `observe().values` 必须含 **`tMax`**（或 `meta.time.maxKey`），结束时 `done === 1`  
   - 角度：滑块用「度」，内部算弧度，读数可再输出 `°`

3. **元数据 `xxxMeta`**  
   - 助学最低集：`title` / `summary` / `concept` / `objectives` / `formulas` / `steps`(含 bindings) / `challenges` / `readouts` / `legend` / `insight`  
   - `views`：至少 `canvas2d` + `docs`；推荐 `chart`、`three`

4. **Adapter + `render*2d.ts`**  
   - Player 只调 adapter；物理公式与专用画面留在 demo  
   - **尽量不改** `DemoPlayer.vue`（壳能力用 `features` / 协议扩展）

5. **注册**  
   - `registerXxxDemo()` → `demos/index.ts` 调用

6. **单测 `*.spec.ts`**  
   - 极限 / 守恒 / 公式一致性 / `tMax` 至少一类

7. **目录与封面**  
   - `LIVE_COVERS[id]` + `public/covers/<id>.png`  
   - 未实现的写 `PLANNED_SOON`（目录显示「敬请期待」）

8. **截图脚本清单**  
   - `scripts/capture-covers.mjs` 的 `ALL_DEMOS` 补上新 id（否则全量抓取不会包含它）

## 2. 教学可视化：做成「能看懂过程」

教材式演示优先**形成过程**，不要只贴最终结果。

| 类型 | 做法（已验证） |
|------|----------------|
| 干涉 / 衍射 | 空间 \|ψ\|² 光场 + 惠更斯波面；探测点标 δ / φ；顶栏公式代入与黄点 I 对照（`drawIntensityFormulaHud`） |
| 偏振（马吕斯） | 自然光星芒 → 起偏刻线 → 线偏光双箭头 → 可转检偏 → 屏光斑；状态对应平行/夹角/消光 |
| 波片 | 分步 ①入射 → ②快慢轴分解+δ → ③ Ex/Ey 矢端轨迹；底栏口诀：同相→线 / 等幅+90°→圆 / 其余→椭圆 |
| 折射 | 法线 + 三线；播放扫描 θ₁；TIR 时明确「折射消失」 |
| 场线 | `isotropic: true` 保证正圆；箭头密度用 `adaptiveFieldDensity`（随视口像素变） |

**对照原则：** 画面上读出的数 = 侧栏公式 bindings = `observe` 同一套符号。顶栏「公式 ↔ 画面」比只写在说明页更有效。

## 3. 封面截图怎么生成

### 3.1 脚本与产物

| 项 | 说明 |
|----|------|
| 脚本 | `scripts/capture-covers.mjs`（Playwright） |
| 输出 | `public/covers/<demo-id>.png` |
| 目录登记 | `src/app/catalog/catalogPlan.ts` → `LIVE_COVERS` |
| 视口 | 优先截 `.viewport.dark canvas`（2D 主画布） |

### 3.2 推荐命令（Windows 注意）

本机 Vite 常绑在 **`localhost`**，而脚本默认 `http://127.0.0.1:5174/...` 可能 **ERR_CONNECTION_REFUSED**。请显式设 `DPH_BASE`：

```powershell
# 1) 另开终端启动开发服
pnpm dev
# 看终端里的 Local 端口，常见 5173 或 5174

# 2) 只重抓某几个（推荐改完画面后用）
$env:DPH_BASE='http://localhost:5174/DrawPhysicsHub'
$env:DPH_COVER_IDS='opt-malus,opt-waveplate'
$env:DPH_COVERS_ALL='1'
node scripts/capture-covers.mjs

# 3) 全量重抓（慢）
$env:DPH_BASE='http://localhost:5174/DrawPhysicsHub'
$env:DPH_COVERS_ALL='1'
node scripts/capture-covers.mjs

# 4) 默认行为：只补「尚不存在」的 png（不设 DPH_COVERS_ALL）
$env:DPH_BASE='http://localhost:5174/DrawPhysicsHub'
node scripts/capture-covers.mjs
```

环境变量：

| 变量 | 含义 |
|------|------|
| `DPH_BASE` | 站点根，须含 Vite `base`（本仓库为 `/DrawPhysicsHub`） |
| `DPH_COVER_IDS` | 逗号分隔 id，只抓这些 |
| `DPH_COVERS_ALL=1` | 强制重抓（覆盖已有 png） |

依赖：`pnpm add -D playwright` 后若无浏览器可 `pnpm exec playwright install chromium`。脚本会依次尝试 Chrome / Edge / 自带 Chromium。

### 3.3 脚本行为（便于排错）

1. 打开 `/s/<学科>/<id>`（学科名会 URL 编码，如 `光学`）  
2. 等约 1.5s；若有「播放」则点一下再「暂停」，让动画落在有内容的一帧  
3. 截主视口 canvas；失败则 `toDataURL`；再失败截 `.stage`

### 3.4 封面质量经验

- 重抓前确认 **HMR 已加载** 最新 `render*2d.ts`（改完渲染再 capture）  
- 默认参数应让封面「一眼能懂」（如波片默认圆偏振、折射空气→玻璃）  
- 顶栏状态条用**屏幕坐标**（见下节），否则封面顶部常被裁切  
- 新 demo 记得同时改：`LIVE_COVERS` + `capture-covers.mjs` 的 `ALL_DEMOS`

## 4. 踩坑清单（高优先级）

### 4.1 状态条 / HUD 被裁切或挡 y 轴

Canvas 里 `sy(world.yMax)` 在**画布上方附近**（y 向下增大）。  
写成 `sy(world.yMax) - 52` 会画到视口外 → 顶栏「被遮挡」。

**正确：** 用屏幕坐标贴顶，例如：

```ts
const boxX = 12
const boxY = 10
ctx.fillRect(boxX, boxY, Math.min(480, W - 24), 44)
```

可复用：`drawIntensityFormulaHud`（干涉/衍射）、马吕斯/波片/折射同款贴顶条。

### 4.2 场线变成椭圆

未开 `drawGridAndAxes2D(..., { isotropic: true })` 时，x/y 像素比例不同，导线 B 圆会扁。  
直导线、点电荷、偶极等场图一律 isotropic。

### 4.3 `select` 参数不显示

`ParamConsole` 早期只画了 `number`。波片类型等需要 `kind: 'select'`，控制台须渲染 `<select>`（已支持 boolean/select）。

### 4.4 封面抓取连不上

- 端口被占用时 Vite 会改到 5174 —— `DPH_BASE` 端口要对上终端输出  
- Windows 上优先 `http://localhost:...` 而不是 `127.0.0.1`

### 4.5 新 demo 目录有卡、封面仍是占位

检查：`LIVE_COVERS` 是否登记、png 是否在 `public/covers/`、`publicAsset` 是否拼了正确 `base`。

### 4.6 改了 DemoPlayer 才能加能力？

优先走协议：`features.charts` / `features.cameraPresets` / adapter 钩子。  
偏振 3D 取景用 `meta.features.cameraPresets` + `ThreeHost.applyView`，避免每个 demo 改壳。

## 5. 可复用模块速查

| 模块 | 用途 |
|------|------|
| `core/render/primitives2d` | 网格轴、箭头、标注、暗色背景 |
| `core/render/adaptiveFieldDensity` | 场线数 / 箭头间距随视口自适应 |
| `core/render/fieldLines2d` + `core/physics/fieldLines` | 电荷场线追踪与绘制 |
| `demos/optics/wavefronts2d` | 相干光场、波面、I(y) 侧栏、公式 HUD、级次标记 |
| `catalogPlan.CATEGORY_ORDER` | 学科内分类教材序 |
| `catalogPlan.PLANNED_SOON` / `LIVE_COVERS` | 预告卡 / 真封面 |

## 6. 测试与抽检

```powershell
pnpm test:mechanics          # 力学

pnpm audit:mechanics         # 跑测并写回 力学包抽检报告

```

## 7. 建议自检清单（发 PR / 收尾前）

- [ ] 目录能打开；播放 / 复位 / scrub 正常  
- [ ] 顶栏或侧栏公式代入与画面黄点/读数一致  
- [ ] 关键色视口无明显裁切、重叠（尤其顶栏与 y 轴）  
- [ ] `*.spec.ts` 绿；相关 audit 绿  
- [ ] `LIVE_COVERS` + png + `capture-covers.mjs` 清单三者齐全  
- [ ] 未实现条目在 `PLANNED_SOON`；分类名在 `CATEGORY_ORDER` 中
