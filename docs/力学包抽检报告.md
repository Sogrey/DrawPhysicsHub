## 抽检原则

1. **极限行为**：边界参数（如 μ≥tanθ 不滑、α=0 时 aₜ=0、波节恒为 0）。
2. **守恒 / 恒等式**：动量、机械能、L_z、aₙρ=v²、v=ωR 等。
3. **协议**：`tMax` / `resolveTMax` 可用，便于 scrub 与循环播放。
4. **不替代教研**：定性结论仍以教材为准；本报告保证「实现与自述公式一致」。
