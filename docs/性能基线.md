# 性能基线（M6-04）

> 目标：中档机主流演示可交互流畅（验收 M6-A2：≥30 fps）  
> 测量日期：2026-11-23 · 构建产物见本地 `pnpm build`

## 构建产物量级

| 项 | 量级 |
|----|------|
| `dist/` 总体 | ~8.4 MB（含 KaTeX 字体 + `public/covers`） |
| 主 JS (`index-*.js`) | ~1.3 MB / gzip ~373 KB |
| 主 CSS | ~47 KB / gzip ~12 KB |
| 告警 | Vite chunk >500 KB（已知，见 [一期已知问题](./一期已知问题.md) K-01） |

尚未做按学科的 code-split；一期可接受，二期可拆包。

## 运行时目标

| 场景 | 目标 | 测法 |
|------|------|------|
| 目录页闲置 | 无明显卡顿 | 滚动 / 搜索 |
| 2D 主流（抛体、双缝、势阱） | ≥30 fps | 播放器内打开「FPS」HUD，播放 10 s |
| 3D 示意（科里奥利、偏振） | ≥30 fps（可关自动旋转） | 同上；斜俯视默认即可 |
| 热学分子 `thermo-gas` | ≥30 fps（默认 N） | 调大 N 时允许下降 |

**参考机型（基线假设）：** 近 5 年集显笔记本 / 办公 PC（如 Intel UHD / Vega），Chrome 或 Edge 最新稳定版，窗口 ≥1280×720。

## 如何自测

1. `pnpm build && pnpm preview`（或线上 Pages）  
2. 打开演示 → 工具栏开启 FPS  
3. 播放默认参数 10 s，读 HUD 平均 fps

## 护栏

- 场线密度走 `adaptiveFieldDensity`，避免固定高密度拖垮弱机  
- 粒子类（`thermo-gas`）默认 N 保守；文档提示勿无上限拉满  
- 复杂 3D 为示意；定量以 2D / bindings 为准
